手绘草稿便利贴 · 风格预览

预览版 · 未部署 · 可回退 v3.3.17

这是一套手绘草稿便利贴设计系统的静态预览，以「今日仪表盘」为样板。 采用纸张点阵纹理、铅笔黑 + 修正红 + 便签黄配色、wobbly 歪扭圆角、无模糊硬偏移阴影、Kalam/Patrick Hand/站酷快乐体手写字体。 仅做 UI 美术替换，业务逻辑与线上 v3.3.17 完全一致，确认风格后再决定是否并入工作台。

组件库

Button / Card / Input 三个可复用组件，均带 hover 抬起、active 按扁、键盘聚焦可见。

Button 按钮

默认白底黑框硬阴影；hover 变红白字并位移；active 阴影消失模拟按扁。

Card 卡片

便利贴模式

便签黄底，适合灵感、临时备忘。

标准卡片

白底铅笔黑框 + 硬阴影，hover 轻微扭动。

Input 输入框

focus 时边框变圆珠笔蓝并出现蓝色光环，移除原生 outline。
